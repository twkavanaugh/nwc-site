# Photographer Shot List — North Wake Church Website (v2, 2026-07-12)

> Changelog — v2: split framing into Overlay/Column recipes; Help pages moved to Column; added 5 Mission entries (2 sourced); about pages excluded.

Working document for the website photography session. Compiled from the live site build + a responsive pilot test of the photo-hero pattern. Questions: Todd.

## Global technical requirements (apply to every website shot)
- **Minimum 2000px wide** delivered (wider is better; we crop, we don't upscale).
- Candid > posed throughout. Warm, natural light preferred.
- Full-resolution originals (we handle web compression/format conversion).

## Framing recipes
Each shot below is tagged with the recipe it must follow.

**RECIPE 1 — OVERLAY** (text is placed over this photo):
- Landscape orientation.
- Key subject framed in the upper two-thirds (the overlay is darkest at the bottom).
- Keep the lower third visually quiet.
- Horizontally center-weighted — on phones the sides crop away hard and only roughly the middle third survives.
- No blown-out white regions dead center (windows, glare, white walls) — headline text sits there over a dark overlay.

**RECIPE 2 — COLUMN** (photo fills a side column, no text overlay):
- Subject centered in frame.
- Composition must survive any crop from 4:5 portrait through square — treat all four edges as expendable.
- No overlay / legibility constraints.
