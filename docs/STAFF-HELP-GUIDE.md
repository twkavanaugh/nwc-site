# North Wake Church Website: Staff Help Guide

How to add and maintain **Events**, **Resources**, **Blog posts**, and the **Current Sermon Series** on northwake.com using Pages CMS.

---

## 1. Before You Start

**How it works.** Everything you edit lives in Pages CMS. When you click **Save**, the website rebuilds itself and your change appears on the live site within a few minutes. If you don't see it yet, wait a couple of minutes and refresh the page.

**Saving publishes.** There is no separate "publish" step. Anything you save is public, unless you've turned on **Draft** (available on Resource text pages and Blog posts).

**The left-hand menu** has one section for each kind of content:

| Section | What it controls |
|---|---|
| **Events** | The Events page and the Events list on the homepage |
| **Resources: links & PDFs** | Downloadable PDFs and links to other websites on the Resources page |
| **Resources: text pages** | Full reading pages on the Resources page (class outlines, guides, policies) |
| **Blog** | The blog, including the weekly Meditation for Preparation |
| **Current Sermon Series** | The "Our Current Study Series" card on the homepage |
| **Media** | The uploaded photos and PDFs themselves (see Section 5) |

**Every field has a hint.** The grey text under each field explains what goes there. When in doubt, read the hint.

## 2. Events

> ### Quick reminder: event dates and featuring
>
> - **Date:** the first (or only) day. Always required.
> - **End date:** only for events longer than one day. Shows the full range ("Sep 24 – 30") and keeps the event listed until it ends.
> - **Stop showing after:** leave blank. If filled in, the event disappears on this date regardless of the event dates. Use it only to hide an event early (registration closed) or keep it listed longer.
> - **Feature on homepage:** puts the event first on the homepage (3 events show). It drops off by itself when the event is over.
>
> **Event won't go away? Clear "Stop showing after."**

### Create an event

1. Go to **Events** and click **Add an entry**.
2. Fill in **Event name** and **Date**. These are the only required fields.
3. Add any optional details you have (see the field guide below). Fields left blank are simply hidden on the site.
4. Write the full description in **Details**.
5. Click **Save**.

### Event field guide

| Field | What to enter | Tips |
|---|---|---|
| **Event name** | The name of the event | Keep it short. It also becomes the page's web address. |
| **Date** | The first (or only) day | Controls the order of events and the big date shown on the site. |
| **Short tagline** | One line under the name | Optional. For example, "Women Encouraging Women." |
| **End date** | The last day, for events longer than one day | See *Dates explained* below. |
| **Stop showing after** | Usually leave blank | See *Dates explained* below. |
| **Time** | For example, "8:30 AM – 3:30 PM" | Free text. Leave blank to hide. |
| **Time note** | A small note under the time | Good for repeating events, such as "Every Wednesday in July." |
| **Location** | Only for off-site events | Leave blank and the church address is used automatically. |
| **Cost** | For example, "Free" or "$25" | Leave blank to hide the cost line. |
| **Deadline text** | For example, "Registration closes April 30" | Shown as written. |
| **Registration link** | Where the Register button goes | A full web address starting with `https://`. Leave blank for no button. |
| **Contact email** | Who to contact with questions | Shown on the event page as text people can copy. |
| **Featured photo** | A wide photo | About 2100 × 800 pixels, under 1MB. See *Photos* below. |
| **Photo description** | A short description of the photo | Read aloud by screen readers. For example, "Families sharing a meal in the fellowship hall." |
| **Ministry** | Which ministry it belongs to | Optional. Not shown on the site yet. |
| **Feature on homepage** | Check to put this event first on the homepage | See *Featuring an event* below. |
| **Details** | The full write-up | Use **Heading 2** for sections such as "Who it's for" and "What's included." |

### Dates explained

This is the part most worth getting right.

- **One-day event:** fill in **Date** only. The event stays listed through that day, then disappears on its own.
- **Multi-day event or weekly series:** fill in **Date** (first day) and **End date** (last day). The site shows the full range, such as "Sep 24 – 30," and keeps the event listed until the end date has passed.
- **Stop showing after:** leave this blank almost always. It overrides the other dates, so the event disappears on this date no matter what the event dates are. Use it only when:
  - you want the event to disappear **early**, for example once registration closes; or
  - you want it to stay listed **longer**, for example an application window that opens before the event.

> **Common mistake:** if an event won't go away (or disappears too soon), check **Stop showing after**. A leftover date there wins over everything else. Clear it.

### Featuring an event on the homepage

The homepage shows up to **3** upcoming events.

- Checked (featured) events appear first, in date order.
- Any open spots fill automatically with the next upcoming events.
- A featured event drops off on its own once it's over, so there's nothing to un-check afterward.

Feature only the events you most want people to see. If everything is featured, nothing stands out.

### Photos for events

- **Use a wide photo, not a poster.** The site crops images into a wide strip, so a flyer with words on it will lose its text. A real photo works best.
- **Aim for about 2100 × 800 pixels and under 1MB.**
- **Always fill in the Photo description.**
- **No photo is fine.** The event page simply shows without one.

### Maintaining events

- **Past events remove themselves.** The site checks dates every day. You don't need to delete old events for them to disappear.
- **Changing details:** open the event, edit, Save.
- **Deleting an event:** see Section 6. You also need to delete its photo.

## 3. Resources

Everything on the Resources page comes from two sections. Choose by asking: **is this a file or link, or is it something people read on our website?**

| If it is... | Use | Shows up as |
|---|---|---|
| A PDF, or a page on another website | **Resources: links & PDFs** | A single row. Clicking downloads the PDF or opens the link. |
| Something to read on our website | **Resources: text pages** | A row that opens its own page on our site |

> **Not a resource:** dated writing with an author, like the weekly meditation, belongs in **Blog** (Section 4).

### 3A. Resources: links & PDFs

1. Go to **Resources: links & PDFs** and click **Add an entry**.
2. Fill in **Title**, **Short description** and **Categories**.
3. Choose a **Type**:

| Type | Use it for | How to fill it in |
|---|---|---|
| **PDF download** | A guide, form, bookmark or handout | **Under about 3MB:** upload it in *PDF file*.<br>**Larger:** put it in the church Google Drive, set sharing to **"Anyone with the link can view,"** and paste that link in *Link*.<br>Use one or the other, never both. |
| **External link** | A page on another website | Paste the full address, starting with `https://`, in *Link*. |

4. Click **Save**.

### 3B. Resources: text pages

1. Go to **Resources: text pages** and click **Add an entry**.
2. Fill in **Title**, **Short description** and **Categories**.
3. Turn **Draft** on while you're still writing. Draft pages are completely hidden.
4. Write the content in **Page text**:
   - Use **Heading 2** for sections.
   - **To show a YouTube video,** paste the YouTube link on a line by itself, with nothing else on that line.
5. **Downloads (optional):** attach up to 5 PDFs, each under about 3MB, with a label such as "Leader Guide (PDF)." They're listed at the bottom of the page. For a larger PDF, put it in the Google Drive and link to it in the page text instead.
6. When it's ready, turn **Draft** off and click **Save**.

> **Choose the title carefully.** The title becomes the page's web address the first time you save. You can rename it later, but the address stays the same.

### Fields every resource has

- **Title:** short and plain, the way someone would search for it.
- **Short description:** one or two sentences on what it is and who it's for. It appears in the list and is used by the Resources search.
- **Categories:** pick at least one. Pick more only if it truly fits. These are the filter buttons on the Resources page. Categories with nothing in them are hidden automatically.
- **Feature at the top of the Resources page:** puts the item in the large photo card at the top of the page.
  - **Feature only one item at a time.** When you feature something new, turn it off on the old one.
  - If the description is long, write a one-sentence version in **Short description for the featured card.**

### Maintaining resources

- **Replacing a PDF with a newer version:** upload the new file, select it in the resource, Save, then delete the old file in Media (Section 6).
- **Retiring a resource:** delete the entry, then delete its file in Media (Section 6).
- **Need a new category?** Ask the web team. Categories can't be added from Pages CMS.

## 4. Blog

### Write a post

1. Go to **Blog** and click **Add an entry**.
2. Turn **Draft** on while you're writing.
3. Fill in **Title**, **Publish date** and **Author**.
4. Choose a **Series** if it belongs to one (for example, *Meditation for Preparation*). Leave blank for a one-off post.
5. Add the optional extras you want (see the field guide below).
6. Write the post in **Post text**.
7. When it's ready, turn **Draft** off and click **Save**.

### Blog field guide

| Field | What to enter | Tips |
|---|---|---|
| **Title** | The post's headline | Becomes the web address on first save. No need to add the series name or date. |
| **Publish date** | The date of the post | Posts are listed newest first by this date. |
| **Author** | Full name | Spell it the same way every time. |
| **Series** | The series it belongs to | Leave blank for a one-off. Ask the web team to add a new series. |
| **Scripture reading** | Reference, and optionally the passage text | Shown in a box at the top of the post. Leave the reference blank to skip it. |
| **Photo** | A wide photo, under about 3MB | Optional. If blank, the series' default photo is used. |
| **Photo description** | A short description of the photo | For screen readers. |
| **Short summary** | One or two sentences | Shown in the blog list. If blank, the first paragraph is used. |
| **Pin to the top of the blog** | Usually leave off | The newest post is shown at the top automatically. Turn on only to hold a post at the top, and turn it off again later. |
| **Draft** | On while writing | Drafts are completely hidden. |
| **Post text** | The post itself | Use the **Quote** button for scripture or other authors. For a YouTube video, put the link on a line by itself. |

### Photos for blog posts

- **Only use photos the church has the right to use:** your own, church photos, or free sites such as Unsplash.
- **Keep files under about 3MB.** The site shrinks them automatically.
- **Always fill in the Photo description.**

## 5. Current Sermon Series

The homepage has an **"Our Current Study Series"** card. It always links to the Sermons page; you only change what it shows. Update it **when a new series starts**.

Unlike the other sections, this is **one form, not a list**. There's nothing to add or delete. Open it, change the details, and Save.

### Update the series

1. Go to **Current Sermon Series**.
2. Change the fields below.
3. Upload the new **Series artwork** and update its **Artwork description**.
4. Click **Save**.
5. Delete the old artwork in **Media → Series artwork** (see Section 6).

| Field | What to enter | Tips |
|---|---|---|
| **Series title** | The series name, e.g. "The Gospel of Luke" | Required. |
| **Subtitle** | A sub-series or theme, e.g. "Welcome: The Heart of Christ" | Optional. |
| **Season** | e.g. "Fall 2026" | Optional. Shown as "Current series · Fall 2026." |
| **Short description** | Two or three sentences about the series | Optional. |
| **Series artwork** | The series title slide | Required. Use the same wide **16:9** graphic shown on the screens on Sunday (e.g. 1920 × 1080), under about 3MB. It's shown whole, never cropped. |
| **Artwork description** | Describe the graphic, including the words on it | Required. For example, "The Gospel of Luke series title over a blue engraving of Jesus teaching." |

> **Safety net:** if the title or artwork is missing, the website refuses to update and keeps showing the last good version. Fill both in and save again.

## 6. Housekeeping

### Deleting something doesn't delete its file

When you delete an event, resource or download, **the uploaded photo or PDF stays on the internet**. Delete it as well:

| What you deleted | Where to delete its file |
|---|---|
| An event with a photo | **Media → Event photos** |
| A PDF resource, or a download on a text page | **Media → Resource PDFs** |
| A blog post with a photo | **Media → Blog photos** (only if no other post uses that photo) |
| Old series artwork, after a new series starts | **Media → Series artwork** |

### File sizes

| Upload | Limit |
|---|---|
| PDFs | Under about **3MB**. Larger: use Google Drive and link to it. |
| Event photos | About 2100 × 800 pixels, under **1MB** |
| Blog photos | Under about **3MB** |
| Series artwork | 16:9 (e.g. 1920 × 1080), under about **3MB** |

An upload that fails with a **"413" error** means the file is too big.

### Good habits

- **Name files clearly before uploading,** for example `half-day-of-prayer-guide.pdf`, not `Scan_0042 final FINAL.pdf`. The file name becomes part of the web address.
- **Check Google Drive sharing** before pasting a link. It must be set to **"Anyone with the link can view,"** or visitors will hit a sign-in screen.
- **Only publish confirmed information.** If a date, name or email isn't confirmed, leave it out or keep the item as a draft. Don't use placeholder text.
- **Write a description for every photo.** It's how visitors using screen readers know what the picture shows.
- **Spell names consistently,** especially blog authors.

## 7. Quick Troubleshooting

| Problem | What to check |
|---|---|
| My change isn't showing | Wait a few minutes and refresh. The site rebuilds after every save. |
| An event won't disappear | Clear **Stop showing after**. |
| An event disappeared too early | Check **Stop showing after** and **End date**. |
| An event isn't on the homepage | The homepage shows 3 events. Check **Feature on homepage** to move it to the front. |
| My upload failed with "413" | The file is over about 3MB. Use Google Drive and a link. |
| A Drive link asks visitors to sign in | Set Drive sharing to "Anyone with the link can view." |
| My page or post isn't showing | Check that **Draft** is turned off. |
| The wrong item is in the featured card | Only one resource should have **Feature** turned on. Turn it off on the others. |
| My YouTube video shows as a plain link | Put the link on its own line, with nothing else on that line. |
| A new blog post isn't at the top | Another post may be pinned. Turn off **Pin to the top of the blog** on it. |
| The homepage still shows the old series | Check that **Current Sermon Series** has a title and artwork, then save again. |
